Aperion Robotics — Developer Handbook

A practical onboarding and CI handbook for the ARISTOS, BlueBOT and shared engineering repositories.

Rollout: Central CI has passed Melodic, Noetic and Lyrical pilot tests; PR #3 remains subject to review. Production activation is phased. Check the current central README for the live policy.

Quick start

  1. Understand the CI policy.
  2. Prepare the workstation, including host-side pre-commit.
  3. Configure VS Code.
  4. Use the ROS1 or ROS2 instructions.
  5. Add repository CI files if the repository has source dependencies or needs CI options.
  6. Follow the PR checklist.

Reference repositories ci-pilot-* to study and understand most of the workflow requirements.

Central CI is authoritative; local checks shorten the feedback loop.
